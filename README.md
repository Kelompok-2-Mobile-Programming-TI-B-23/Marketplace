# Clothtify

Clothtify is a user-friendly mobile marketplace for clothing that helps customers discover, filter, and purchase fashion items quickly and securely. The platform focuses on a curated product catalog (merchants are onboarded externally) with rich product pages, reliable checkout, and community Q&A per product.

A mobile marketplace application built with Flutter, allowing users to browse, search, and purchase products.

## Features

- User authentication
- Product listing and details
- Shopping cart and checkout
- E-wallet integration
- Profile management
- Search, sorting, and filter products

## Getting Started

### Prerequisites

- [Flutter SDK](https://flutter.dev/docs/get-started/install)
- Android Studio or VS Code
- Android/iOS emulator or device

### Installation

1. Clone the repository:
   ```bash
   git clone <repo-url>
   cd Marketplace
   ```
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run the app:
   flutter run
   ```

## Project Structure

- `lib/` - Main application code
- `assets/` - Images, icons, fonts
- `android/` & `ios/` - Platform-specific files
- `test/` - Unit and widget tests
